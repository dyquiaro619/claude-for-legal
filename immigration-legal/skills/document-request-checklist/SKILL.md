# Document Request Checklist Skill

Use this skill when the user wants a structured document request list based on an immigration intake summary, consultation note, declaration, or humanitarian case narrative.

## Purpose

Generate a clean, organized document request checklist for the client and legal team.

This skill supports asylum, humanitarian, TPS, removal defense, U visa, VAWA, and related immigration workflows.

## Core Rules

- Do not request unnecessary sensitive documents.
- Do not assume documents exist if not mentioned.
- If evidence appears weak, identify additional corroborating evidence that may help.
- Organize requests clearly and simply.
- Separate attorney/internal notes from client-facing language.
- Label all outputs as attorney-review drafts.

## Output Format

# Draft Document Request Checklist

**Attorney Review Draft**

## 1. Identity Documents

Request items such as:

- Passport
- National ID
- Birth certificate
- Marriage certificate
- Children's birth certificates
- Driver’s license or state ID
- Prior immigration documents

## 2. Immigration History Documents

Examples:

- Visa records
- I-94
- Notice to Appear
- Prior USCIS notices
- Prior applications or petitions
- Work permits
- Removal paperwork
- Court notices
- Detention paperwork

## 3. Humanitarian / Asylum Evidence

Examples:

- Threatening messages
- Police reports
- Photos or videos
- Political affiliation evidence
- Protest participation evidence
- Social media evidence
- Country conditions materials
- Witness statements
- Medical records
- Psychological evaluations

## 4. Family & Relationship Documents

Examples:

- Family member IDs
- Marriage records
- Custody records
- School records
- Affidavits from relatives

## 5. Timeline Clarification Requests

List missing timeline details the firm still needs clarified.

## 6. Additional Corroborating Evidence

Suggest optional evidence that may strengthen the matter.

## 7. Internal Attorney Notes

Include:

- Weakest evidence area
- Biggest credibility concern
- Missing corroboration
- Urgent evidence needs
- Items staff should prioritize first

## 8. Client Communication Draft

Create a short client-facing message explaining:

- Why the documents matter
- How to submit them
- What to do if they cannot obtain certain documents
- Whether translation may be needed

End with:

“Attorney review required before sending this checklist to the client.”
